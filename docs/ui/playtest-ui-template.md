# Feedback lượt chơi UI

Dùng cho `proto/game.html`. Nên thử bằng máy tính và chuột. Không cần đọc spec, lời giải hoặc làm T1–T21 để góp ý giao diện.

## Cách thử

Chơi từ **Bắt đầu điều tra** khoảng 20 phút, đọc **Cách chơi** nếu cần. Tự chọn phòng, người muốn hỏi và thí nghiệm. Khi kẹt, ghi lại trước khi nhờ người chỉ. Chưa giải được vụ án vẫn gửi feedback được. Đừng tải lại giữa lượt vì bản này chưa lưu tiến trình.

## Chỗ bị vướng — mỗi vấn đề một dòng

| Màn / thời điểm | Tôi muốn làm gì | Tôi đã bấm / kéo gì | Tôi nghĩ sẽ xảy ra gì | Thực tế / chỗ không hiểu |
|---|---|---|---|---|
| | | | | |

Có ảnh thì kèm ảnh; giữ nguyên lời bạn dùng, không cần mô tả kỹ thuật.
